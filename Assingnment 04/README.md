
# My Styled Portfolio

## About the Project
This is my personal portfolio website created using HTML and CSS.
It represents my introduction, education, hobbies, skills, projects and goals.

## Technologies Used
- HTML5
- CSS3
- Google Fonts

## Design Choices

### Colour Palette
- Dark Navy: Used for the header and footer to create a professional look.
- Off-white: Used as the main background for a clean appearance.
- Teal Green: Used as an accent colour to highlight important elements.
- White: Used for content cards.
- Grey: Used for secondary text and borders.

### Typography
- Outfit: Used for headings because it has a modern and bold appearance.
- DM Sans: Used for body text because it is clean and readable.

### Layout
- Cards are used to separate different sections.
- Hover effects provide interaction.
- Responsive CSS makes the website suitable for smaller screens.
- CSS variables help maintain consistent colours, fonts and spacing.
